## What is Travelia?

Travelia is a travel booking landing page — *"Explore the World."* It presents travel destinations in a card layout, with a search section and a booking call-to-action. The site is fully static with no backend or API calls.

---

## Features

- **Hero section** — full-width travel imagery with headline and search bar
- **Destination cards** — locations displayed with photos, names, and highlights
- **Booking CTA** — call-to-action section prompting users to book
- **Travel packages section** — curated package listings
- **Responsive layout** — adapts from mobile to widescreen
